# FX Wishlist

환율 변동에 따른 해외직구 상품의 원화 가격을
확인할 수 있는 위시리스트 웹 서비스입니다.

## 주요 기능
- 상품 등록, 조회, 수정, 삭제
- Frankfurter API를 통한 환율 데이터 수집
- 환율 기반 원화 가격 계산
- 상품별 가격 변동 그래프

## 기술 스택
- Backend: Python, FastAPI
- Database: SQLite
- Data Processing: Pandas
- Frontend: HTML, CSS, JavaScript

## 실행 방법
1. 저장소 클론
2. 가상환경 생성 및 활성화
3. pip install -r requirements.txt
4. FastAPI 서버 실행
5. 로컬 주소로 접속
